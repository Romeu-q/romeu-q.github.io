// =====================================================================
//  ÍCONES 16x16  ->  assets/img/pixel/icon-*.svg
// ---------------------------------------------------------------------
//  COMO EDITAR (vale para todos os .txt desta pasta):
//   - Linhas que começam com // são comentários.
//   - @sprite nome        começa um sprite novo (vira <dir>/<nome>.svg)
//   - @dir pasta          pasta de saída padrão (relativa à raiz do site)
//   - @scale n            width/height = grid * n (o viewBox é sempre o grid)
//   - @out a.svg b.svg    caminhos de saída explícitos (substitui @dir)
//   - @palette            linhas "X #rrggbb [opacidade]" (char -> cor).
//                         Já existe uma paleta padrão (tools/lib/palette.mjs):
//                         K ink, k ink-soft, W branco, C creme, S sky, s sky claro,
//                         B sky-deep, d azul fundo, A aqua, a aqua-light, t teal,
//                         G leaf, g leaf-dark, l leaf claro, Y sun, y sun escuro,
//                         O coral, o coral escuro, P pink, p pink escuro,
//                         n pele, m pele sombra, h cabelo, H cabelo luz, r/R cinzas.
//   - @grid [mirror] [outline=K]
//                         grid ASCII; '.' = transparente. Todas as linhas com o
//                         mesmo tamanho (o gerador acusa erro se não).
//                         mirror: você desenha só a metade esquerda e ela é espelhada.
//                         outline=K: contorno automático de 1px (4 vizinhos) na cor K.
//   - @layer id [x=0 y=0] [hidden]
//                         camada extra dentro de <g id="id"> (para animar via CSS).
//                         hidden = some só na prévia PNG (o CSS cuida do resto).
//   - @extends outro      copia grid+camadas de outro sprite; @drop id remove camada.
//   - @patch [x= y=]      sobrepõe pixels no grid base; '_' apaga o pixel.
//   - @style              CSS cru dentro do <style> do SVG.
//   - @motion             CSS de animação — o gerador embrulha automaticamente em
//                         @media (prefers-reduced-motion: no-preference).
//  Depois de editar:  node tools/pixel2svg.mjs
// =====================================================================
